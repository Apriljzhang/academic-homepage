# TIRF workshop: trainee walkthrough and revisions

Reviewed on 23 October 2026 from the perspective of an English teacher attending the workshop for the first time. This is a walkthrough of the material and its interactions, rather than feedback collected from workshop participants.

The assessment content was present, but the transitions assumed familiarity with AI tools and website files. The revisions keep the seven-page sequence, original framework models, two classroom scenarios, bilingual controls and assessment focus.

| Page | A teacher's likely question | Revision |
| --- | --- | --- |
| 1. Aims | What will I be able to do by the end? | Kept three outcomes; described the practical outcome as building and trying one assessment website. Made list numbering visible. |
| 2. Primary English | Is the incorrect English an instruction or a pupil's answer? | Labelled the sample pupil response explicitly; removed a repeated introductory paragraph. Retained Chinese support, pointing and paper/oral responses. |
| 3. College English | Which student's work do the later feedback examples address? | Added the sample reason and first draft used by the framework prompts, with a short teacher check. Included the same evidence in copied scenario context. |
| 4. Frameworks | Must I copy every prompt? Are examples AI instructions? Is personal praise recommended? | Explained the difference between classroom examples and independent chatbot prompts. Clarified feedback terms, marked personal praise as feedback to improve and moved the guidance beside the levels. Kept the original Black & Wiliam matrix and the connected diagram after all three models. Added a phone scrolling hint. |
| 5. Build | What is index.html? Which prompt should I use? How do I open the result? | Explained the single-file website, provided three numbered steps and an expandable preview guide. Made the choice between Scenario 1, Scenario 2 and the own-class form explicit. Put copy buttons before long prompt text. Generalised form guidance for both contexts. |
| 6. Use | What do I do with the site and the evidence? | Linked rehearsal with sample answers to the same assessment steps used in class. Made collection before feedback, checking interpretations and selecting prepared feedback explicit. Removed repeated projector guidance. Kept improvement in the same agent task. |
| 7. Share | Do I need to publish? What do GitHub's terms mean? | Kept publishing optional; added a conditional Sites route and a copyable publishing request. Explained repository, main and root within the numbered GitHub Pages instructions. Retained the device-based collection method. |
